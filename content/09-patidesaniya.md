{% heading pali="Pāṭidesanīya" english="Pāṭidesanīya" /%}

{% passage %}
{% pali %}
Ime kho pan'āyasmanto ***cattāro pāṭidesanīyā dhammā*** uddesaṁ āgacchanti.
{% /pali %}
{% english %}
Venerable sirs, these ***four actions entailing acknowledgement*** come up for recitation.
{% /english %}
{% /passage %}

{% rule class="patidesaniya" n=1 %}
{% pali %}
Yo pana bhikkhu aññātikāya bhikkhuniyā antara-gharaṁ paviṭṭhāya hatthato, khādanīyaṁ vā bhojanīyaṁ vā sahatthā paṭiggahetvā khādeyya vā bhuñjeyya vā, paṭidesetabbaṁ tena bhikkhunā, "Gārayhaṁ āvuso dhammaṁ āpajjiṁ asappāyaṁ pāṭidesanīyaṁ, taṁ paṭidesemī" ti.
{% /pali %}
{% english %}
Should any bhikkhu chew or consume staple or non-staple food, having received it with his own hand from the hand of an unrelated bhikkhunī in an inhabited area, he is to acknowledge it: "Friends, I have committed a blameworthy, unsuitable act that ought to be acknowledged. I acknowledge it."
{% /english %}
{% /rule %}

{% rule class="patidesaniya" n=2 %}
{% pali %}
Bhikkhū pan'eva kulesu nimantitā bhuñjanti. Tatra ce bhikkhunī vosāsamāna-rūpā ṭhitā hoti, "Idha sūpaṁ detha, idha odanaṁ dethā" ti. Tehi bhikkhūhi sā bhikkhunī apasādetabbā, "Apasakka tāva bhagini, yāva bhikkhū bhuñjantī" ti. Ekassa'pi ce bhikkhuno nappaṭibhāseyya taṁ bhikkhuniṁ apasādetuṁ, "Apasakka tāva bhagini, yāva bhikkhū bhuñjantī" ti, paṭidesetabbaṁ tehi bhikkhūhi, "Gārayhaṁ āvuso dhammaṁ āpajjimhā asappāyaṁ pāṭidesanīyaṁ, taṁ paṭidesemā" ti.
{% /pali %}
{% english %}
In case bhikkhus, being invited, are eating in family residences, and if a bhikkhunī is standing there as though giving directions, (saying,) "Give curry here, give rice here," then the bhikkhus are to dismiss her: "Go away, sister, while the bhikkhus are eating." If not one of the bhikkhus should speak to dismiss her, "Go away, sister, while the bhikkhus are eating," the bhikkhus are to acknowledge it: "Friends, we have committed a blameworthy, unsuitable act that ought to be acknowledged. We acknowledge it."
{% /english %}
{% /rule %}

{% rule class="patidesaniya" n=3 %}
{% pali %}
Yāni kho pana tāni sekkha-sammatāni kulāni. Yo pana bhikkhu tathā-rūpesu sekkha-sammatesu kulesu pubbe animantito agilāno khādanīyaṁ vā bhojanīyaṁ vā sahatthā paṭiggahetvā khādeyya vā bhuñjeyya vā, paṭidesetabbaṁ tena bhikkhunā, "Gārayhaṁ āvuso dhammaṁ āpajjiṁ asappāyaṁ pāṭidesanīyaṁ, taṁ paṭidesemī" ti.
{% /pali %}
{% english %}
There are families designated as in training. Should any bhikkhu, not being ill, uninvited beforehand, chew or consume staple or non-staple food, having received it himself at the residences of families designated as in training, he is to acknowledge it: "Friends, I have committed a blameworthy, unsuitable act that ought to be acknowledged. I acknowledge it."
{% /english %}
{% /rule %}

{% rule class="patidesaniya" n=4 %}
{% pali %}
Yāni kho pana tāni āraññakāni senāsanāni sāsaṅka-sammatāni sappaṭibhayāni. Yo pana bhikkhu tathā-rūpesu senāsanesu viharanto, pubbe appaṭisaṁviditaṁ khādanīyaṁ vā bhojanīyaṁ vā ajjhārāme sahatthā paṭiggahetvā agilāno khādeyya vā bhuñjeyya vā, paṭidesetabbaṁ tena bhikkhunā, "Gārayhaṁ āvuso dhammaṁ āpajjiṁ asappāyaṁ pāṭidesanīyaṁ, taṁ paṭidesemī" ti.
{% /pali %}
{% english %}
There are wilderness lodgings that are considered dubious and risky. Should any bhikkhu, not being ill, living in such lodgings, chew or consume (a gift of) staple or non-staple food that was unannounced beforehand, having received it with his own hand in the lodging, he is to acknowledge it: "Friends, I have committed a blameworthy, unsuitable act that ought to be acknowledged. I acknowledge it."
{% /english %}
{% /rule %}

{% passage %}
{% pali %}
Uddiṭṭhā kho āyasmanto cattāro pāṭidesanīyā dhammā.
{% /pali %}
{% english %}
Venerable sirs, the four actions entailing acknowledgement have been recited.
{% /english %}
{% /passage %}

{% passage kind="pucchami" %}
{% pali %}
{% lines %}
Tatth'āyasmante pucchāmi:\
Kacci'ttha parisuddhā?\
Dutiyam-pi pucchāmi:\
Kacci'ttha parisuddhā?\
Tatiyam-pi pucchāmi:\
Kacci'ttha parisuddhā?
{% /lines %}

Parisuddh'etth'āyasmanto, tasmā tuṇhī, evam-etaṁ dhārayāmi.
{% /pali %}
{% english %}
{% lines %}
Thus I ask the venerable ones:\
Are you pure in this?\
A second time I ask:\
Are you pure in this?\
A third time I ask:\
Are you pure in this?
{% /lines %}

The venerable ones are pure in this, which is why they are silent. Thus do I hold it.
{% /english %}
{% /passage %}

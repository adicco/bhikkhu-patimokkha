{% heading level=3 pali="Sīluddesa-pāṭha" english="The Summary on Virtue" /%}

{% passage %}
{% pali %}
{% call %}Handa mayaṁ sīluddesa-pāṭhaṁ bhaṇāma se:{% /call %}

{% lead %}Bhāsitam-idaṁ{% /lead %} tena bhagavatā jānatā passatā arahatā sammā-sambuddhena: "Sampanna-sīlā bhikkhave viharatha sampanna-pāṭimokkhā. Pāṭimokkha-saṁvara-saṁvutā viharatha ācāra-gocara-sampannā. Aṇumattesu vajjesu bhaya-dassāvī samādāya sikkhatha sikkhāpadesū" ti.

Tasmā tih'amhehi sikkhitabbaṁ: "Sampanna-sīlā viharissāma sampanna-pāṭimokkhā. Pāṭimokkha-saṁvara-saṁvutā viharissāma ācāra-gocara-sampannā. Aṇumattesu vajjesu bhaya-dassāvī samādāya sikkhissāma sikkhāpadesū" ti. Evañ-hi no sikkhitabbaṁ.
{% /pali %}
{% english %}
{% call %}Let us recite the summary on virtue:{% /call %}

This was said by the Blessed One, the One who Knows, the One who Sees, the Worthy One Rightly Self-awakened: "Live consummate in virtue, bhikkhus, and consummate in the Pāṭimokkha. Live restrained with the restraint of the Pāṭimokkha, consummate in your behavior & sphere of activity. Train yourselves, having undertaken the training rules, seeing danger in the slightest faults."

Therefore we should train ourselves: "We will live consummate in virtue, consummate in the Pāṭimokkha. We will live restrained with the restraint of the Pāṭimokkha, consummate in our behavior & sphere of activity. We will train ourselves, having undertaken the training rules, seeing danger in the slightest faults." That's how we should train ourselves.
{% /english %}
{% /passage %}

{% stanza %}
Yaṅ-kiñci sithilaṁ kammaṁ\

{% english %}
{% call %}Let us recite the verses to Tāyana:{% /call %}

{% stanza %}
Having striven, brahman, cut the stream.\
Expel sensual passions.\
Without abandoning sensual passions\
a sage encounters no oneness of mind.
{% /stanza %}

{% stanza %}
If something's to be done,\
then work at it firmly,\
for a slack going-forth\
kicks up all the more dust.
{% /stanza %}

{% stanza %}
It's better to leave a misdeed undone.\
A misdeed burns you afterward.\
Better that a good deed be done\
that, when you've done it, you don't regret.
{% /stanza %}

{% stanza %}
Just as sharp-bladed grass, if wrongly held,\
wounds the very hand that holds it,\
the contemplative life, if wrongly grasped,\
drags you down to hell.
{% /stanza %}

{% stanza %}
Any slack act,\
defiled observance,\
or fraudulent life of celibacy\
{% indent /%}bears no great fruit.
{% /stanza %}
{% /english %}

{% heading level=3 pali="Ovāda-pāṭimokkha Gāthā" english="Pāṭimokkha Exhortation Verses" /%}

{% passage %}
{% pali %}
{% lead %}Uddiṭṭhaṁ kho{% /lead %} tena bhagavatā jānatā passatā arahatā sammā-sambuddhena: Ovāda-pāṭimokkhaṁ tīhi gāthāhi.

{% stanza %}
Khantī paramaṁ tapo tītikkhā\
Nibbānaṁ paramaṁ vadanti buddhā,\
Na hi pabbajito parūpaghātī\
Samaṇo hoti paraṁ viheṭhayanto.
{% /stanza %}

{% stanza %}
Sabba-pāpassa akaraṇaṁ\
{% indent /%}Kusalassūpasampadā\
Sacitta-pariyodapanaṁ\
{% indent /%}Etaṁ buddhāna-sāsanaṁ.
{% /stanza %}

{% stanza %}
Anūpavādo anūpaghāto\
{% indent /%}Pāṭimokkhe ca saṁvaro\
Mattaññutā ca bhattasmiṁ\
{% indent /%}Pantañ-ca sayan'āsanaṁ.\
Adhicitte ca āyogo\
{% indent /%}Etaṁ buddhāna-sāsanan'ti.
{% /stanza %}
{% /pali %}
{% english %}
This was summarized by the Blessed One, the One who Knows, the One who Sees, the Worthy One Rightly Self-awakened—the Pāṭimokkha Exhortation in three verses:

{% stanza %}
Patient forbearance is the highest austerity.\
Unbinding is highest say the Buddhas.\
He is no monk who injures another;\
nor a contemplative,\
he who oppresses another.
{% /stanza %}

{% stanza %}
The non-doing of all evil,\
the performance of what is skillful,\
the cleansing of one's own mind:\
{% indent /%}That is the Buddhas' teaching.
{% /stanza %}

{% stanza %}
Not disparaging, not injuring,\
restraint in line with the Pāṭimokkha,\
moderation in food,\
dwelling in seclusion,\
commitment to the heightened mind:\
{% indent /%}That is the Buddhas' teaching.
{% /stanza %}
{% /english %}
{% /passage %}

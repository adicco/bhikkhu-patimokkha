{% passage %}
{% pali %}
{% changed %}Pavāraṇā{% /changed %}-karaṇato pubbe nava-vidhaṁ pubba-kiccaṁ kātabbaṁ hoti:

{% lines %}
Taṇṭhāna-sammajjanañ-ca;\
tattha padīp'ujjalanañ-ca;\
āsana-paññapanañ-ca;\
pānīya-paribhojanīyūpaṭṭhapanañ-ca;\
chandārahānaṁ bhikkhūnaṁ chandāharaṇañ-ca;\
tesaññeva {% changed %}akata-pavāraṇānaṁ pavāraṇāya-pi{% /changed %} āharaṇañ-ca;\
utukkhānañ-ca;\
bhikkhu-gaṇanā ca;\
bhikkhunīnam-ovādo cā'ti.
{% /lines %}

Tattha purimesu catūsu kiccesu padīpa-kiccaṁ idāni {% sic correction="suriy'ālokassa" %}suriya-lokassa{% /sic %} atthitāya n'atthi. Aparāni tīṇi bhikkhūnaṁ vattaṁ jānantehi bhikkhūhi katāni pariniṭṭhitāni honti.

Chandāharaṇa {% changed %}pavāraṇā{% /changed %}-āharaṇāni pana imissaṁ sīmāyaṁ hattha-pāsaṁ vijahitvā nisinnānaṁ bhikkhūnaṁ abhāvato n'atthi.

Utukkhānaṁ nāma, ettakaṁ atikkantaṁ ettakaṁ avasiṭṭhanti evaṁ utu-ācikkhanaṁ. Utūnīdha pana sāsane hemanta-gimha-vassānānaṁ vasena tīṇi honti.

Ayaṁ vassānotu. Imasmiñ-ca utumhi satta ca uposathā ekā ca pavāraṇā. Iminā pakkhena—

{% lines indent=true %}
{% changed %}ekā pavāraṇā sampattā{% /changed %},\
pañca uposathā atikkantā,\
{% var note="p1" %}dve uposathā avasiṭṭhā{% /var %}.
{% /lines %}

Iti evaṁ sabbehi āyasmantehi utukkhānaṁ {% sic correction="dhāretabbaṁ" %}dhāretabbam{% /sic %}.
{% /pali %}
{% /passage %}

{% passage %}
{% pali %}
Bhikkhunīnam-ovādo pana idāni tāsaṁ natthitāya n'atthi.

Iti sakaraṇ'okāsānaṁ pubba-kiccānaṁ katattā, nikkaraṇ'okāsānaṁ pubba-kiccānaṁ pakatiyā pariniṭṭhitattā.

Evan-taṁ navavidhaṁ pubba-kiccaṁ pariniṭṭhitaṁ hoti.

Niṭṭhite ca pubba-kicce.

Sace so divaso cātuddasī-paṇṇarasī-sāmaggīnamaññataro yathājja {% changed %}pavāraṇā paṇṇarasī [cātuddasī]{% /changed %},

{% list %}
1. yāvatikā ca bhikkhū kammappattā {% changed %}saṅgha-pavāraṇārahā, pañca{% /changed %} vā tato vā atirekā pakatattā pārājikaṁ anāpannā saṅghena vā anukkhittā,
2. te ca kho hatthapāsaṁ avijahitvā eka-sīmāyaṁ ṭhitā,
3. tesañ-ca vikāla-bhojanādivasena vatthu-sabhāgāpattiyo ce na vijjanti,
4. tesañ-ca hatthapāse hatthapāsato bahikaraṇavasena vajjetabbo koci vajjanīya-puggalo ce n'atthi.
{% /list %}

Evan-taṁ {% changed %}pavāraṇā{% /changed %}-kammaṁ imehi catūhi lakkhaṇehi saṅgahitaṁ pattakallaṁ nāma hoti, kātuṁ {% sic correction="yuttarūpaṁ" %}yuttarūpam{% /sic %}.

{% heading level=3 english="The Motion" /%}

{% passage %}
{% pali %}
Suṇātu me bhante saṅgho. Ajja pavāraṇā paṇṇarasī [cātuddasī]. Yadi saṅghassa pattakallaṁ, saṅgho te-vācikaṁ pavāreyya.
{% /pali %}
{% english %}
"Venerable sirs, may the Community listen to me. Today is the Invitation day on the fifteenth [fourteenth]. If the Community is ready, the Community should invite with three statements."
{% /english %}
{% /passage %}

{% instruction %}
If the Invitation is a harmony Invitation, change *paṇṇarasī* to *sāmaggī.*

If each bhikkhu is to state his invitation twice, the word *te-vācikaṁ* should be changed to *dve-vācikaṁ*. If once, to *eka-vācikaṁ*.
{% /instruction %}

{% heading level=3 english="The Invitation" /%}

{% passage speaker="Senior bhikkhu" %}
{% pali %}
Saṅghaṁ āvuso pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Dutiyam-pi āvuso saṅghaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Tatiyam-pi āvuso saṅghaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.
{% /pali %}
{% english %}
"Friends, I invite the Community. With regard to what is seen, heard, or suspected, may you speak to me out of sympathy. On seeing (the offense) I will make amends. A second time…. A third time, friends, I invite the Community…. On seeing (the offense) I will make amends."
{% /english %}
{% /passage %}

{% instruction %}
The remaining bhikkhus then state their invitations in line with seniority, changing "*Saṅghaṁ āvuso*" to "*Saṅgham-bhante*," and "*āvuso*" to "*bhante*"—i.e., "friends" to "venerable sirs," thus:
{% /instruction %}

{% passage %}
{% pali %}
Saṅgham-bhante pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Dutiyam-pi bhante saṅghaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Tatiyam-pi bhante saṅghaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.
{% /pali %}
{% /passage %}

{% heading level=2 english="Group & Individual Pavāraṇā" /%}

{% instruction %}
**Mutual Invitation.** If the assembly contains four bhikkhus, the motion is:
{% /instruction %}

{% passage %}
{% pali %}
Suṇantu me āyasmanto. Ajja pavāraṇā paṇṇarasī [cātuddasī]. Yad'āyasmantānaṁ pattakallaṁ, mayaṁ aññam-aññaṁ pavāreyyāma.
{% /pali %}
{% english %}
This means: "Listen to me, sirs. Today is the Invitation day on the fifteenth [fourteenth]. If you are ready, we should invite one another."
{% /english %}
{% /passage %}

{% instruction %}
The bhikkhus should then invite one another, in line with seniority. Because there are so few of them, each should invite three times:
{% /instruction %}

{% passage %}
{% pali %}
Ahaṁ āvuso [bhante] āyasmante pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Dutiyam-pi āvuso [bhante] āyasmante pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.

Tatiyam-pi āvuso [bhante] āyasmante pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya. Passanto paṭikkarissāmi.
{% /pali %}
{% english %}
This means: "Friends [venerable sirs], I invite you. With regard to what is seen, heard, or suspected, may you speak to me out of sympathy. On seeing (the offense) I will make amends. A second time…. A third time, friends [venerable sirs], I invite you…. On seeing (the offense) I will make amends."
{% /english %}
{% /passage %}

{% instruction %}
If the assembly contains three bhikkhus, they follow the same procedure as for four, except that *āyasmanto* is changed to *āyasmantā*, both in the motion and in the invitation, as is appropriate when addressing two rather than three people.

If the assembly contains only two bhikkhus, they do not make a motion. Each simply invites the other, saying:
{% /instruction %}

{% passage %}
{% pali %}
Aham āvuso [bhante] āyasmantaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadatu maṁ āyasmā anukampaṁ upādāya. Passanto paṭikkarissāmi.

Dutiyam-pi āvuso [bhante] āyasmantaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadatu maṁ āyasmā anukampaṁ upādāya. Passanto paṭikkarissāmi.

Tatiyam-pi āvuso [bhante] āyasmantaṁ pavāremi. Diṭṭhena vā sutena vā parisaṅkāya vā, vadatu maṁ āyasmā anukampaṁ upādāya. Passanto paṭikkarissāmi.
{% /pali %}
{% /passage %}

{% instruction %}
**Determination.** If the assembly consists of only one bhikkhu, he is to prepare the place as he would for determining an uposatha observance. When he is sure that no one is coming, he may determine his Invitation:
{% /instruction %}

{% passage align="center" %}
{% pali %}
Ajja me pavāraṇā.
{% /pali %}
{% english %}
(Today is my Invitation.)
{% /english %}
{% /passage %}

{% instruction %}
As with the uposatha, the Commentary recommends adding *paṇṇarasī* (the fifteenth) or *cātuddasī* (the fourteenth) at the end of the determination, but this is optional.
{% /instruction %}

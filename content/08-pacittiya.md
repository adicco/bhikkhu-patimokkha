{% heading pali="Pācittiya" english="Pācittiya" /%}

{% passage %}
{% pali %}
Ime kho pan'āyasmanto ***dve-navuti pācittiyā dhammā*** uddesaṁ āgacchanti.
{% /pali %}
{% english %}
Venerable sirs, these ***ninety-two actions entailing confession*** come up for recitation.
{% /english %}
{% /passage %}

{% rule class="pacittiya" n=1 %}
{% pali %}
Sampajāna-musāvāde pācittiyaṁ.
{% /pali %}
{% english %}
A deliberate lie is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=2 %}
{% pali %}
Omasavāde pācittiyaṁ.
{% /pali %}
{% english %}
An insult is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=3 %}
{% pali %}
Bhikkhu-pesuññe pācittiyaṁ.
{% /pali %}
{% english %}
Malicious tale-bearing among bhikkhus is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=4 %}
{% pali %}
Yo pana bhikkhu anupasampannaṁ padaso dhammaṁ vāceyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu have an unordained person recite Dhamma line by line (with him), it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=5 %}
{% pali %}
Yo pana bhikkhu anupasampannena uttari-dviratta-tirattaṁ saha-seyyaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu lie down together (in the same dwelling) with an unordained person for more than two or three (consecutive) nights, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=6 %}
{% pali %}
Yo pana bhikkhu mātugāmena saha-seyyaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu lie down together (in the same dwelling) with a woman, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=7 %}
{% pali %}
Yo pana bhikkhu mātugāmassa uttari-chappañca-vācāhi dhammaṁ deseyya, aññatra viññunā purisa-viggahena, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu teach more than five or six sentences of Dhamma to a woman—unless a knowledgeable man is present—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=8 %}
{% pali %}
Yo pana bhikkhu anupasampannassa uttari-manussa-dhammaṁ āroceyya, bhūtasmiṁ pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu report (his own) superior human state to an unordained person, when it is factual, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=9 %}
{% pali %}
Yo pana bhikkhu bhikkhussa duṭṭhullaṁ āpattiṁ anupasampannassa āroceyya aññatra bhikkhu-sammatiyā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu report (another) bhikkhu's serious offense to an unordained person—unless authorized by the bhikkhus—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=10 %}
{% pali %}
Yo pana bhikkhu paṭhaviṁ khaṇeyya vā khaṇāpeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu dig soil or have it dug, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=11 %}
{% pali %}
Bhūtagāma-pātabyatāya pācittiyaṁ.
{% /pali %}
{% english %}
The damaging of a living plant is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=12 %}
{% pali %}
Aññavādake vihesake pācittiyaṁ.
{% /pali %}
{% english %}
Evasive speech and causing frustration are to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=13 %}
{% pali %}
Ujjhāpanake khiyyanake pācittiyaṁ.
{% /pali %}
{% english %}
Criticizing or complaining (about a Community official) is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=14 %}
{% pali %}
Yo pana bhikkhu saṅghikaṁ mañcaṁ vā pīṭhaṁ vā bhisiṁ vā kocchaṁ vā ajjhokāse santharitvā vā santharāpetvā vā, taṁ pakkamanto n'eva uddhareyya na uddharāpeyya, anāpucchaṁ vā gaccheyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu set a bed, bench, mattress, or stool belonging to the Community out in the open—or have it set out—and then on departing neither put it away nor have it put away, or should he go without taking leave, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=15 %}
{% pali %}
Yo pana bhikkhu saṅghike vihāre seyyaṁ santharitvā vā santharāpetvā vā, taṁ pakkamanto n'eva uddhareyya na uddharāpeyya, anāpucchaṁ vā gaccheyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu set out bedding in a dwelling belonging to the Community—or have it set out—and then on departing neither put it away nor have it put away, or should he go without taking leave, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=16 %}
{% pali %}
Yo pana bhikkhu saṅghike vihāre jānaṁ pubbūpagataṁ bhikkhuṁ anūpakhajja seyyaṁ kappeyya, "Yassa sambādho bhavissati, so pakkamissatī" ti. Etad'eva paccayaṁ karitvā anaññaṁ, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu knowingly lie down in a dwelling belonging to the Community so as to intrude on a bhikkhu who arrived there first, (thinking,) "Whoever finds it confining will go away"—doing it for just that reason and no other—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=17 %}
{% pali %}
Yo pana bhikkhu bhikkhuṁ kupito anattamano saṅghikā vihārā nikkaḍḍheyya vā nikkaḍḍhāpeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, angered and displeased, evict a bhikkhu from a dwelling belonging to the Community—or have him evicted—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=18 %}
{% pali %}
Yo pana bhikkhu saṅghike vihāre upari-vehāsa-kuṭiyā āhacca-pādakaṁ mañcaṁ vā pīṭhaṁ vā abhinisīdeyya vā abhinipajjeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sit or lie down on a bed or bench with detachable legs on an (unplanked) loft in a dwelling belonging to the Community, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=19 %}
{% pali %}
Mahallakam-pana bhikkhunā vihāraṁ kārayamānena, yāva dvāra-kosā aggalaṭṭhapanāya, āloka-sandhi-parikammāya, dvitticchadanassa pariyāyaṁ, appaharite ṭhitena adhiṭṭhātabbaṁ. Tato ce uttariṁ appaharite-pi ṭhito adhiṭṭhaheyya, pācittiyaṁ.
{% /pali %}
{% english %}
When a bhikkhu is having a large dwelling built, he may supervise two or three layers of facing to plaster the area around the window frame and reinforce the area around the door frame the width of the door opening, while standing where there are no crops to speak of. Should he supervise more than that, even if standing where there are no crops to speak of, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=20 %}
{% pali %}
Yo pana bhikkhu jānaṁ sappāṇakaṁ udakaṁ tiṇaṁ vā mattikaṁ vā siñceyya vā siñcāpeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu knowingly pour water containing living beings—or have it poured—on grass or on clay, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=21 %}
{% pali %}
Yo pana bhikkhu asammato bhikkhuniyo ovadeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, unauthorized, exhort the bhikkhunīs, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=22 %}
{% pali %}
Sammato-pi ce bhikkhu atthaṅgate suriye bhikkhuniyo ovadeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, even if authorized, exhort the bhikkhunīs after sunset, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=23 %}
{% pali %}
Yo pana bhikkhu bhikkhunūpassayaṁ upasaṅkamitvā bhikkhuniyo ovadeyya aññatra samayā, pācittiyaṁ. Tatthāyaṁ samayo: Gilānā hoti bhikkhunī. Ayaṁ tattha samayo.
{% /pali %}
{% english %}
Should any bhikkhu, having gone to the bhikkhunīs' quarters, exhort the bhikkhunīs—except at the proper occasion—it is to be confessed. Here the proper occasion is this: A bhikkhunī is ill. This is the proper occasion here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=24 %}
{% pali %}
Yo pana bhikkhu evaṁ vadeyya, "Āmisa-hetu bhikkhū bhikkhuniyo ovadantī" ti, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu say that the bhikkhus exhort the bhikkhunīs for the sake of worldly gain, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=25 %}
{% pali %}
Yo pana bhikkhu aññātikāya bhikkhuniyā cīvaraṁ dadeyya, aññatra pārivaṭṭakā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu give robe-cloth to a bhikkhunī unrelated to him—except in exchange—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=26 %}
{% pali %}
Yo pana bhikkhu aññātikāya bhikkhuniyā cīvaraṁ sibbeyya vā sibbāpeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sew a robe or have it sewn for a bhikkhunī unrelated to him, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=27 %}
{% pali %}
Yo pana bhikkhu bhikkhuniyā saddhiṁ saṁvidhāya ek'addhāna-maggaṁ paṭipajjeyya, antamaso gām'antaram-pi aññatra samayā, pācittiyaṁ. Tatthāyaṁ samayo: Sattha-gamanīyo hoti maggo sāsaṅka-sammato sappaṭibhayo. Ayaṁ tattha samayo.
{% /pali %}
{% english %}
Should any bhikkhu, by arrangement, travel together with a bhikkhunī even for the interval between one village and the next—except at the proper occasion—it is to be confessed. Here the proper occasion is this: The road is to be traveled by caravan and is considered dubious and risky. This is the proper occasion here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=28 %}
{% pali %}
Yo pana bhikkhu bhikkhuniyā saddhiṁ saṁvidhāya ekaṁ nāvaṁ abhirūheyya, uddha-gāminiṁ vā adho-gāminiṁ vā, aññatra tiriy'antaraṇāya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, by arrangement, get in the same boat with a bhikkhunī going upstream or downstream—except to cross over to the other bank—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=29 %}
{% pali %}
Yo pana bhikkhu jānaṁ bhikkhunī-paripācitaṁ piṇḍapātaṁ bhuñjeyya, aññatra pubbe gihi-samārambhā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu knowingly eat almsfood donated through the prompting of a bhikkhunī—except for food that householders had already intended for him—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=30 %}
{% pali %}
Yo pana bhikkhu bhikkhuniyā saddhiṁ eko ekāya raho nisajjaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sit in private, alone with a bhikkhunī, it is to be confessed.
{% /english %}
{% /rule %}

{% vagga pali="Ovāda-vaggo tatiyo." english="(Here ends) the third chapter, on exhortation." /%}

{% rule class="pacittiya" n=31 %}
{% pali %}
Agilānena bhikkhunā eko āvasatha-piṇḍo bhuñjitabbo. Tato ce uttariṁ bhuñjeyya, pācittiyaṁ.
{% /pali %}
{% english %}
A bhikkhu who is not ill may eat one meal at a public alms center. If he should eat more than that, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=32 %}
{% pali %}
Gaṇa-bhojane aññatra samayā, pācittiyaṁ. Tatthāyaṁ samayo: gilāna-samayo, cīvara-dāna-samayo, cīvara-kāra-samayo, addhāna-gamana-samayo, nāvābhirūhana-samayo, mahā-samayo, samaṇa-bhatta-samayo. Ayaṁ tattha samayo.
{% /pali %}
{% english %}
A group meal—except at the proper occasions—is to be confessed. Here the proper occasions are these: a time of illness, a time of giving cloth, a time of making robes, a time of going on a journey, a time of embarking on a boat, a great occasion, a time when the meal is supplied by contemplatives. These are the proper occasions here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=33 %}
{% pali %}
Parampara-bhojane aññatra samayā, pācittiyaṁ. Tatthāyaṁ samayo: gilāna-samayo, cīvara-dāna-samayo, cīvara-kāra-samayo. Ayaṁ tattha samayo.
{% /pali %}
{% english %}
An out-of-turn meal—except at the proper occasions—is to be confessed. Here the proper occasions are these: a time of illness, a time of giving cloth, a time of making robes. These are the proper occasions here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=34 %}
{% pali %}
Bhikkhuṁ pan'eva kulaṁ upagataṁ pūvehi vā manthehi vā abhihaṭṭhum-pavāreyya, ākaṅkhamānena bhikkhunā dvitti-patta-pūrā paṭiggahetabbā. Tato ce uttariṁ paṭiggaṇheyya, pācittiyaṁ. Dvitti-patta-pūre paṭiggahetvā tato nīharitvā bhikkhūhi saddhiṁ saṁvibhajitabbaṁ. Ayaṁ tattha sāmīci.
{% /pali %}
{% english %}
In case a bhikkhu arriving at a family residence is presented with cakes or cooked grain-meal, he may accept two or three bowlfuls if he so desires. If he should accept more than that, it is to be confessed. Having accepted the two-or-three bowlfuls and having taken them from there, he is to share them among the bhikkhus. This is the proper course here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=35 %}
{% pali %}
Yo pana bhikkhu bhuttāvī pavārito anatirittaṁ khādanīyaṁ vā bhojanīyaṁ vā khādeyya vā bhuñjeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, having eaten and turned down an offer (of further food), chew or consume staple or non-staple food that is not leftover, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=36 %}
{% pali %}
Yo pana bhikkhu bhikkhuṁ bhuttāviṁ pavāritaṁ anatirittena khādanīyena vā bhojanīyena vā abhihaṭṭhum-pavāreyya, "Handa bhikkhu khāda vā bhuñja vā" ti, jānaṁ āsādan'āpekkho, bhuttasmiṁ pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu, knowingly and wishing to find fault, present staple or non-staple food he has brought to a bhikkhu who has eaten and turned down an offer (of further food), (saying,) "Here, bhikkhu, chew or consume this"—when it has been eaten, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=37 %}
{% pali %}
Yo pana bhikkhu vikāle khādanīyaṁ vā bhojanīyaṁ vā khādeyya vā bhuñjeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu chew or consume staple or non-staple food at the wrong time, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=38 %}
{% pali %}
Yo pana bhikkhu sannidhi-kārakaṁ khādanīyaṁ vā bhojanīyaṁ vā khādeyya vā bhuñjeyya vā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu chew or consume stored-up staple or non-staple food, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=39 %}
{% pali %}
Yāni kho pana tāni paṇīta-bhojanāni, seyyathīdaṁ: sappi navanītaṁ telaṁ madhu phāṇitaṁ, maccho maṁsaṁ khīraṁ dadhi. Yo pana bhikkhu eva-rūpāni paṇīta-bhojanāni agilāno attano atthāya viññāpetvā bhuñjeyya, pācittiyaṁ.
{% /pali %}
{% english %}
There are these finer staple foods: ghee, fresh butter, oil, honey, sugar/molasses, fish, meat, milk, and curds. Should any bhikkhu who is not ill, having requested finer staple foods such as these for his own sake, then consume them, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=40 %}
{% pali %}
Yo pana bhikkhu adinnaṁ mukha-dvāraṁ āhāraṁ āhareyya, aññatra udaka-dantapoṇā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu take into his mouth an edible that has not been given—except for water and tooth-cleaning sticks—it is to be confessed.
{% /english %}
{% /rule %}

{% vagga pali="Bhojana-vaggo catuttho." english="(Here ends) the fourth chapter, on food." /%}

{% rule class="pacittiya" n=41 %}
{% pali %}
Yo pana bhikkhu acelakassa vā paribbājakassa vā paribbājikāya vā sahatthā khādanīyaṁ vā bhojanīyaṁ vā dadeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu give staple or non-staple food with his own hand to a naked ascetic, a male wanderer, or a female wanderer, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=42 %}
{% pali %}
Yo pana bhikkhu bhikkhuṁ evaṁ vadeyya: "Eh'āvuso gāmaṁ vā nigamaṁ vā piṇḍāya pavisissāmā" ti. Tassa dāpetvā vā adāpetvā vā uyyojeyya, "Gacch'āvuso. Na me tayā saddhiṁ kathā vā nisajjā vā phāsu hoti. Ekakassa me kathā vā nisajjā vā phāsu hotī" ti. Etad'eva paccayaṁ karitvā anaññaṁ, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu say to a bhikkhu, "Come, my friend, let's enter the village or town for alms," and then—whether or not he has had (food) given to him—dismiss him, (saying,) "Go away, my friend. I don't like sitting or talking with you. I prefer sitting or talking alone"—doing it for just that reason and no other—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=43 %}
{% pali %}
Yo pana bhikkhu sabhojane kule anūpakhajja nisajjaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sit intruding on a family "with its meal," it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=44 %}
{% pali %}
Yo pana bhikkhu mātugāmena saddhiṁ raho paṭicchanne āsane nisajjaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sit in private on a secluded seat with a woman, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=45 %}
{% pali %}
Yo pana bhikkhu mātugāmena saddhiṁ eko ekāya raho nisajjaṁ kappeyya, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu sit in private, alone with a woman, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=46 %}
{% pali %}
Yo pana bhikkhu nimantito sabhatto samāno santaṁ bhikkhuṁ anāpucchā pure-bhattaṁ vā pacchā-bhattaṁ vā kulesu cārittaṁ āpajjeyya aññatra samayā, pācittiyaṁ. Tatthāyaṁ samayo: cīvara-dāna-samayo, cīvara-kāra-samayo. Ayaṁ tattha samayo.
{% /pali %}
{% english %}
Should any bhikkhu, being invited for a meal and without taking leave of an available bhikkhu, go calling on families before or after the meal—except at the proper occasions—it is to be confessed. Here the proper occasions are these: a time of giving cloth, a time of making robes. These are the proper occasions here.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=47 %}
{% pali %}
Agilānena bhikkhunā cātu-māsa-paccaya-pavāraṇā sāditabbā, aññatra puna-pavāraṇāya, aññatra nicca-pavāraṇāya. Tato ce uttariṁ sādiyeyya, pācittiyaṁ.
{% /pali %}
{% english %}
A bhikkhu who is not ill may accept (make use of) a four-month invitation to ask for requisites. If he should accept (make use of) it beyond that—unless the invitation is renewed or is permanent—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=48 %}
{% pali %}
Yo pana bhikkhu uyyuttaṁ senaṁ dassanāya gaccheyya, aññatra tathā-rūpa-paccayā, pācittiyaṁ.
{% /pali %}
{% english %}
Should any bhikkhu go to see an army on active duty—unless there is a suitable reason—it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=49 %}
{% pali %}
Siyā ca tassa bhikkhuno kocid'eva paccayo senaṁ gamanāya, dviratta-tirattaṁ tena bhikkhunā senāya vasitabbaṁ. Tato ce uttariṁ vaseyya, pācittiyaṁ.
{% /pali %}
{% english %}
There being some reason or another for a bhikkhu to go to an army, he may stay two or three (consecutive) nights with the army. If he should stay beyond that, it is to be confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=50 %}
{% pali %}
Dviratta-tirattañ-ce bhikkhu senāya vasamāno, uyyodhikaṁ vā balaggaṁ vā senā-byūhaṁ vā anīka-dassanaṁ vā gaccheyya, pācittiyaṁ.
{% /pali %}
{% english %}
If a bhikkhu staying two or three nights with an army should go to a battlefield, a roll call, the troops in battle formation, or to see a review of the (battle) units, it is to be confessed.

{% /pali %}
{% english %}
When a bhikkhu is having a sitting cloth made, it is to be made to the standard measurement. Here the standard is this: two spans—using the sugata span—in length, one and a half in width, the border a span. In excess of that, it is to be cut down and confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=90 %}
{% pali %}
Kaṇḍu-paṭicchādiṁ pana bhikkhunā kārayamānena pamāṇikā kāretabbā. Tatr'idaṁ pamāṇaṁ: dīghaso catasso vidatthiyo sugata-vidatthiyā, tiriyaṁ dve vidatthiyo. Taṁ atikkāmayato, chedanakaṁ pācittiyaṁ.
{% /pali %}
{% english %}
When a bhikkhu is having a skin-eruption covering cloth made, it is to be made to the standard measurement. Here the standard is this: four spans—using the sugata span—in length, two in width. In excess of that, it is to be cut down and confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=91 %}
{% pali %}
Vassika-sāṭikaṁ pana bhikkhunā kārayamānena pamāṇikā kāretabbā. Tatr'idaṁ pamāṇaṁ: dīghaso cha vidatthiyo sugata-vidatthiyā tiriyaṁ aḍḍha-teyyā. Taṁ atikkāmayato, chedanakaṁ pācittiyaṁ.
{% /pali %}
{% english %}
When a bhikkhu is having a rains-bathing cloth made, it is to be made to the standard measurement. Here the standard is this: six spans—using the sugata span—in length, two and a half in width. In excess of that, it is to be cut down and confessed.
{% /english %}
{% /rule %}

{% rule class="pacittiya" n=92 %}
{% pali %}
Yo pana bhikkhu sugata-cīvarappamāṇaṁ cīvaraṁ kārāpeyya atirekaṁ vā, chedanakaṁ pācittiyaṁ. Tatr'idaṁ sugatassa sugata-cīvarappamāṇaṁ: dīghaso nava vidatthiyo sugata-vidatthiyā, tiriyaṁ cha vidatthiyo. Idaṁ sugatassa sugata-cīvarappamāṇaṁ.
{% /pali %}
{% english %}
Should any bhikkhu have a robe made the measurement of the sugata robe or larger, it is to be cut down and confessed. Here, the measurement of the Sugata's sugata robe is this: nine spans—using the sugata span—in length, six spans in width. This is the measurement of the Sugata's sugata robe.
{% /english %}
{% /rule %}

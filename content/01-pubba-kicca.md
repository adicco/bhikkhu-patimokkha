{% pali %}
*Okāsaṁ me bhante thero detu, pāṭimokkhaṁ uddesituṁ.*
{% /pali %}
{% english %}
*May the senior monk give me the opportunity to recite the Pāṭimokkha.*
{% /english %}
{% /passage %}

{% heading pali="Pubba-kiccaṁ" english="Preliminary Duties" /%}

{% passage %}
{% pali %}
Uposatha-karaṇato pubbe nava-vidhaṁ pubba-kiccaṁ kātabbaṁ hoti:

{% lines %}
taṇṭhāna-sammajjanañ-ca;\
tattha padīp'ujjalanañ-ca;\
āsana-paññapanañ-ca;\
pānīya-paribhojanīyūpaṭṭhapanañ-ca;\
chandārahānaṁ bhikkhūnaṁ chandāharaṇañ-ca;\
tesaññeva akat'uposathānaṁ pārisuddhiyā-pi āharaṇañ-ca;\
utukkhānañ-ca;\
bhikkhu-gaṇanā ca;\
bhikkhunīnam-ovādo cā'ti.
{% /lines %}
{% /pali %}
{% english %}
Before doing the Uposatha, the ninefold preliminary duty should be done:

{% lines %}
sweeping the place;\
lighting a lamp there;\
preparing the seats;\
setting out water for drinking and washing;\
conveying the consent of the bhikkhus who should give their consent;\
conveying the purity of those same bhikkhus who do not join in the Uposatha;\
season-telling;\
bhikkhu-counting; and\
instructing the bhikkhunīs.
{% /lines %}
{% /english %}
{% /passage %}

{% english %}
{% slot name="time" %}With regard to the first four of these, there is no lamp-duty because of the current presence of sunlight. The remaining three{% /slot %} have been done by {% slot name="helpers" %}bhikkhus{% /slot %} who know the bhikkhus' duties. These are therefore completed.
{% /english %}

{% passage %}
{% pali %}
Chandāharaṇa pārisuddhi-āharaṇāni pana imissaṁ sīmāyaṁ hattha-pāsaṁ vijahitvā nisinnānaṁ bhikkhūnaṁ abhāvato n'atthi.
{% /pali %}
{% english %}
There is no conveying of consent or purity because in this territory there are no bhikkhus sitting outside the hatthapāsa.
{% /english %}
{% /passage %}

{% passage %}
{% pali %}
Utukkhānaṁ nāma, ettakaṁ atikkantaṁ ettakaṁ avasiṭṭhanti evaṁ utu-ācikkhanaṁ. Utūnīdha pana sāsane hemanta-gimha-vassānānaṁ vasena tīṇi honti.
{% /pali %}
{% english %}
Season-telling means declaring the season thus: "This number (of Uposathas) is past; this number remains."

In this Teaching there are three seasons: winter, summer, and the rainy season.
{% /english %}
{% /passage %}

Bhikkhu-gaṇanā nāma imasmiṁ uposath'agge uposathatthāya sannipatitā bhikkhū ettakāti bhikkhūnaṁ gaṇanā. Imasmim-pana uposath'agge {% slot name="bhikkhus" %}{% var note="6" %}cattāro{% /var %}{% /slot %} bhikkhū sannipatitā honti. Iti sabbehi āyasmantehi bhikkhu-gaṇanā-pi dhāretabbā.
{% /pali %}
{% english %}
Bhikkhu-counting means counting the number of bhikkhus, (saying,) "This number of bhikkhus has gathered in this Uposatha hall for the purpose of the Uposatha." And in this Uposatha hall {% slot name="bhikkhus" %}{% var %}four{% /var %}{% /slot %} bhikkhus have gathered.

That's how the venerable ones should all remember the bhikkhu-counting.
{% /english %}
{% /passage %}

{% response pali="Evaṁ, bhante" english="Yes, venerable sir" /%}

{% passage %}
{% pali %}
Bhikkhunīnam-ovādo pana idāni tāsaṁ natthitāya n'atthi.
{% /pali %}
{% english %}
There is no instructing of the bhikkhunīs because they now do not exist.
{% /english %}
{% /passage %}

{% passage %}
{% pali %}
Iti sakaraṇ'okāsānaṁ pubba-kiccānaṁ katattā, nikkaraṇ'okāsānaṁ pubba-kiccānaṁ pakatiyā pariniṭṭhitattā.

Evan-taṁ nava-vidhaṁ pubba-kiccaṁ pariniṭṭhitaṁ hoti.
{% /pali %}
{% english %}
Thus the ninefold preliminary duty has been completed by the doing of what there is occasion to do and by the very nature of what there is no occasion to do.
{% /english %}
{% /passage %}

{% passage %}
{% pali %}
Niṭṭhite ca pubba-kicce, sace so divaso cātuddasī-paṇṇarasī-sāmaggīnamaññataro yathājja uposatho {% slot name="day" fifteenth="paṇṇaraso" fourteenth="cātuddaso" %}paṇṇaraso [cātuddaso]{% /slot %},

{% list %}
1. yāvatikā ca bhikkhū kammappattā saṅgh'uposathārahā, cattāro vā tato vā atirekā pakatattā pārājikaṁ anāpannā saṅghena vā anukkhittā,
2. te ca kho hatthapāsaṁ avijahitvā eka-sīmāyaṁ ṭhitā,
3. tesañ-ca vikāla-bhojanādivasena vatthu-sabhāgāpattiyo ce na vijjanti,
4. tesañ-ca hatthapāse hatthapāsato bahikaraṇavasena vajjetabbo koci vajjanīya-puggalo ce n'atthi.
{% /list %}

Evan-taṁ uposatha-kammaṁ imehi catūhi lakkhaṇehi saṅgahitaṁ pattakallaṁ nāma hoti, kātuṁ yuttarūpaṁ.

Uposatha-kammassa pattakallattaṁ viditvā idāni kariyamāno uposatho saṅghena anumānetabbo.
{% /pali %}
{% english %}
When the preliminary duty has been completed, if the day is either the fourteenth, the fifteenth, or the harmony day—as today is the {% slot name="day" fifteenth="fifteenth" fourteenth="fourteenth" %}fifteenth [fourteenth]{% /slot %}—then:

{% list %}
1. if the bhikkhus coming to the transaction and appropriate for the Saṅgha-uposatha number four or more, being regular bhikkhus who have neither committed a pārājika offense nor been suspended by the Saṅgha;
2. if they have not left the hatthapāsa to remain within the territory;
3. if they have no offenses in common, such as eating food at the wrong time; and
4. if there is, within the hatthapāsa, no disqualified person who should be expelled outside the hatthapāsa,
{% /list %}

then the Uposatha-transaction endowed with these four characteristics is said to be ready and fit to be done.

Knowing the Uposatha-transaction to be ready, the Saṅgha may infer that the Uposatha should now be done.
{% /english %}
{% /passage %}
